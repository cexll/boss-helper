# 岗位筛选增强与 Jev 方向判断：PRD 与执行规格

- 需求来源：`CONTEXT.md`「求职辅助术语与关系」一节（岗位筛选、投递体验与后台运行、关于页）。本文件与其冲突时以 `CONTEXT.md` 为准，并同步修正本文件。
- 用户确认：2026-09-26 在对话中确认共同理解与范围删减。本文件不构成发布、提交或真实投递的授权。
- 暂缓范围：自动回复、简历发送、Jev 话术选择见 `CONTEXT.md`「暂缓范围」，本期不实现。

## PRD

### Problem Statement

现有岗位名称、职位描述筛选只能在“包含”和“排除”之间二选一，英文按子串匹配（Java 会命中 JavaScript），职位描述还带有会误伤包含词的隐含规则；岗位方向只能靠关键词粗判，容易投递不相关岗位；判断服务不可用时没有“暂不投递、稍后再判”的处置。

### Goals

- G1 更细的关键词筛选：同字段包含与排除并存，包含词可选任一或全部满足，匹配语义可预期。
- G2 Jev 方向判断：避免投递不相关岗位，判断不了时进入待复核而不是放行或永久排除。
- G3 投递体验：减少无效详情请求、重复判断和无效等待；切换标签页后任务继续；不降低现有安全间隔。

### Non-goals

- 正则表达式；公司、地点、招聘者职务的候选增强；自动提词、预设词库、收藏、别名自动扩展。
- Jev 故障时放行；第三方中转；以其他模型替代 Jev；Jev 改写或挑选话术。
- 改变公司、薪资、规模、地图等现有筛选在缺字段时的行为；改变现有 AI 筛选自身行为。
- 关闭页面或离线运行；提高平台请求并发；缩短安全间隔、延迟与上限。
- 自动回复、简历发送（暂缓范围）。

### Users / Actors

求职者（插件用户）、Boss 直聘网站、Jev 判断服务（用户自备密钥）。

### Functional Requirements

- FR-001 岗位名称与职位描述各自支持包含组和排除组；包含组可选任一或全部满足；可只设排除组；排除词命中任意一个即拒绝。
- FR-002 规则为空不能启用；同一词同时在包含组与排除组时提示冲突，修正前不能启用。
- FR-003 匹配语义：中文按包含；英文忽略大小写按完整词；后接数字视为版本号仍命中（Vue→Vue3）；后接字母不命中（Java↛JavaScript）；C++、C#、.NET 为完整名称，C 不命中 C++/C#。
- FR-004 职位描述中排除词前五个字内有“不”或“无”不算命中；包含词不做否定判断；岗位名称不做否定判断；关键词后接“系统、软件、工具、服务”不再阻止命中。
- FR-005 候选词只来自用户用过的关键词，可多选也可自由输入，不会自动成为条件。
- FR-006 旧配置原样迁移：原“包含”词进入包含组并设为任一满足，原“排除”词进入排除组，启用状态不变。
- FR-010 启用 Jev 需用户自备密钥与非空目标岗位方向；密钥只存浏览器存储；启用时展示接收服务并取得授权。
- FR-011 发给 Jev 的数据仅限岗位标题和职位描述；岗位文字只作为被判断内容，不能扩大权限或触发动作。
- FR-012 同一阶段硬条件（非模型判断的已启用筛选）先于 Jev，AI 筛选在 Jev 之后；Jev 先仅凭标题判断，明确不相关则跳过且不再获取详情；标题阶段不确定时，获取详情且职位描述关键词通过后再判断一次。
- FR-013 Jev 报错、超时、不确定，或关键词/Jev 所需字段缺失时，岗位进入待复核：当次不投递、不记为排除、不缓存，再次扫到重新判断。
- FR-014 待复核列表只在当前页面显示，刷新后清空；用户可重试、跳过或人工确认方向；人工确认仅对当前岗位与当前目标有效，确认后仍须通过其他筛选；投递统计单独计数待复核。
- FR-015 Jev 明确结果与人工确认按“岗位 + 判定依据”缓存；判定依据为目标岗位方向描述与所用 Jev 模型标识，任一变化即失效。
- FR-016 Jev 与现有 AI 筛选各自开关；Jev 在前，方向不匹配的岗位不进入 AI 筛选。
- FR-017 插件页面无法直接访问 Jev 时由扩展后台发起请求；仍不可达则 Jev 功能不交付并如实说明。
- FR-020 切换标签页后任务继续；浏览器限制导致暂停时如实提示。
- FR-021 提速只通过减少重复判断、无效详情请求与无效等待实现。
- FR-030 关于页保留精简版本，移除赞赏区块。

### Acceptance Criteria

- AC-001 包含 Java、排除“外包”：“JavaScript 外包”被拒绝；“Java 开发”通过；“Java8 开发”通过。
- AC-002 C 不命中 “C++”“C#”；React 命中 “React开发”。
- AC-003 空规则、包含与排除含同一词：均不能启用。
- AC-004 职位描述“无外包”不被排除词“外包”拒绝；“不加班，Java开发”命中包含词 Java；“Java系统开发”命中包含词 Java。
- AC-005 旧版包含/排除配置升级后，对同一批不涉及 FR-003/FR-004 语义变化的岗位，筛选结果与升级前一致。
- AC-006 密钥或目标方向为空时 Jev 不能启用。
- AC-007 已被本地硬条件排除的岗位不产生 Jev 请求；标题阶段判为不相关的岗位不产生详情请求，也不调用 AI 筛选。
- AC-008 Jev 超时或不确定：岗位进入待复核、未投递、统计计数加一；再次扫到时重新请求 Jev。
- AC-009 同一岗位同一目标第二次扫到不再请求 Jev；修改目标方向后重新请求。
- AC-010 人工确认只放行当前岗位，同名其他岗位仍需判断；确认后命中排除词仍不投递。
- AC-011 发给 Jev 的请求只含岗位标题与职位描述。
- AC-012 Jev 不可达时界面说明原因，没有以其他模型判断。
- AC-013 切换标签页后任务继续；请求间隔不短于现有下限，并发不增加。
- AC-014 关于页无赞赏区块。

### Edge Cases / Failure Handling

Jev 故障/超时/不确定 → 待复核；目标变化 → 缓存与人工确认失效；页面刷新 → 待复核列表清空；浏览器节流 → 如实提示；Jev 不可达 → 功能不交付。

### Constraints

`useApplying` 的间隔、延迟、上限是防封号安全措施，不得削弱；旧配置必须可加载；投递流水线、配置与请求模块为关键路径，逐行人工审查；匹配与处置逻辑放在 `.ts` 模块以接受覆盖率门禁。

## Execution Spec

### Scope

In scope：FR-001～FR-030。Out of scope：Non-goals 全部内容。

### Terms / Assumptions

- 待复核是岗位处置结果，与流水线步骤结果 done / skip / abort 分开建模。
- Jev 超时秒数、“不确定”的判定方式、缓存保存期限由 P5 实测后在实现前定下并回写本文件。
- 人工确认是持久记录（随 Jev 缓存），待复核列表不持久。

### Prerequisites（真实网站/服务只读实测）

- P4 切换标签页后流水线计时与请求是否被浏览器节流及其程度。
- P5 Jev 接口可否从插件页面或扩展后台访问；实际发出的数据；超时与不确定结果的表现。

### Affected Surfaces

- Code：投递流水线筛选与处置、Jev 请求、设置界面、统计、关于页。
- Data / schema：持久化配置新增字段与旧配置迁移；持久化投递统计新增待复核计数（旧统计须可加载）；Jev 结果缓存。
- API / UI：设置页关键词组与 Jev 配置、待复核列表、统计计数。
- Tests：匹配语义、迁移往返、处置与缓存、Jev 数据组装。
- Docs / ops：无发布动作。
