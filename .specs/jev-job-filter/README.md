## 估时

单位：人天，指一名熟悉仓库的开发者在 AI 辅助下完成实现、测试与本地门禁的工作量，不含人工审查等待。

| 里程碑     | 任务                                                         | 小计 |
| ---------- | ------------------------------------------------------------ | ---- |
| m0-probe   | p1 0.5、p2 0.5                                               | 1    |
| m1-keyword | t0 0.5、t1 1、t2 0.5、t6 1、t3 1、t4 1.5、t12 0.25、v-m1 0.5 | 6.25 |
| m2-jev     | t5 1、t7 0.5、t8 1、t9 0.5、t10 1、v-m2 0.5                  | 4.5  |

| m3-runtime | t11 0.5                                                      | 0.5  |
| 合计       | 20 项                                                        | 13   |

- 关键路径：t0 → t1 → t2 → t3 → t7 → t8 → t9 → t10 → v-m2 → a-final → a-promote = 7.25 人天；近关键支路 p1 → t5 → t8 要求 p1 在第 2.5 天前完成，否则关键路径延长到 7.75 人天。
- 单人串行：约 13 人天工作量；加 20–30% 余量（关键路径人工逐行审查、仓库遗留门禁红灯、Jev 接口形态未知）约 16–17 个工作日，约 3.5 周。
- 两条并行线（例如一人走关键路径，另一人或代理做 t6、t4、t12、p2、t11）：约 8–9 个工作日，约 2 周。
- 估时依据任务规模推断，未经实测校准；p1 结果若显示需要改走扩展后台或 Jev 响应不含可用的不确定信号，t5、t8 可能各增加 0.5–1 人天；若 Jev 完全不可达，m2 停止，剩余交付约 7.5 人天（m0、m1、m3 与验收）。
